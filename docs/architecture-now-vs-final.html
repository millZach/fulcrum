The final version

graph orchestration + gauntlet loop

One Mastra macro graph owns the macro decisions; bounded specialist loops (attempts, time, cost, termination) do the local work inside each node. Each node gets a compact context envelope, independent nodes fan out in parallel under the budget, and humans are interrupted only at high-leverage gates. The Gauntlet closes the loop: findings flow back into production until the slice is genuinely good.
